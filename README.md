## Why this page exists

The design seed — the pattern docs, architecture decision records, the
pre-registered claims register, and the graded build logs — lived at this
address until 2026-09-19, when it moved into the organization with its dated
commit history.

Some permanent records were made before the move and still cite this address:
the `m2-close` release archived by Zenodo, and the `m2-close` tags of the
organization's repos as archived by Software Heritage. GitHub does not redirect
a repository that was moved this way, so this page is the signpost.
